# 风险案例配对对比、清除率与包级标记（tab4_contrasts.py 生成）

定义与分母：陷阱失败 = 冻结评分器的 `trapFellAny`（金标陷阱失败事件，含签名命中、需求状态越界与分族额外规则），只在风险案例（positive_risk，每模型 72 例）上定义，不可解析产物为空值。配对对比 X→Y 的配对 n = 在 X 与 Y 下 `trapFellAny` 都非空的风险案例数；修复 b = X 失败且 Y 未失败的配对案例数，新增 c = X 未失败且 Y 失败，同失败 = 两者都失败，同通过 = 两者都未失败；两条件的率 = 该条件失败数 / 配对 n（括号内为失败数）；差值 = (c − b) / 配对 n，即后 − 前，单位 pp。95% CI 为 Newcombe (1998) 配对差方法 10：两个边际率各取无连续性校正的 Wilson 区间，用 φ 系数平方相加合成，φ 的分子 ad − bc 在 ad > bc 时换成 max(ad − bc − n/2, 0)，任一边际为 0 时 φ = 0（标准库自实现，并对 Newcombe 1998 表 III 的方法 8/10 数值自检通过）。p 为精确 McNemar 双侧 p = min(1, 2·P(X ≤ min(b, c)))，X ~ Bin(b + c, 1/2)。清除率 = C2→C4 的 b / C2 失败的配对案例数（= b + 同失败），Wilson 95% CI。三模型合并 = 把三个模型的配对案例堆叠成一个 2×2 表后计算同样的量（案例在模型间重复出现，合并不是独立样本）。分族计数只描述、不检验（每族 12 个风险案例）。包级标记率 = 校验器聚合结论为 BLOCK 或 HUMAN_REVIEW 的案例数 / 该组全部案例（风险 72、对照 72，含不可解析产物；不可解析产物一律被标记）；C3 = 对冻结 C2 产物的离线校验，C0、C1、C5 的标记同样是生成后离线打分，生成时没有执行校验。包级标记不是检测指标。

## 6. 断言：进入 C4 的对比中 McNemar p 与 2·0.5^b

- gpt-oss:20b · C2->C4：c = 0，b = 15，p = 6.10e-05 = 2·0.5^15（断言通过）
- gpt-oss:20b · C0->C4：c = 0，b = 39，p = 3.64e-12 = 2·0.5^39（断言通过）
- qwen3:8b · C2->C4：c = 0，b = 23，p = 2.38e-07 = 2·0.5^23（断言通过）

- qwen3:30b-a3b · C0->C4：c = 2 ≠ 0，恒等式不适用，p = 2.15e-10
- pooled · C2->C4：c = 0，b = 52，p = 4.44e-16 = 2·0.5^52（断言通过）

c = 0 时精确 McNemar 退化为 b 个不一致对的符号检验，p 只是 b 的函数；C2→C4 的 c = 0 是修复器的设计属性，p 只进表或补充材料。
